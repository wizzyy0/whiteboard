# 🖌️ Интерактивный учебный вайтборд

Простая и быстрая рисовалка в стиле Excalidraw для уроков: работает прямо в браузере, ничего скачивать не нужно. Рисунки сохраняются автоматически.

## Возможности

- **Инструменты**: кисть, ластик, линия, стрелка, 2D-фигуры (прямоугольник, эллипс, треугольник), **лассо** — обведите нужное и перетащите
- **3D-фигуры**: куб, параллелепипед, пирамида, призма, цилиндр, конус, шар — невидимые рёбра рисуются пунктиром
- **Цвета**: 3 быстрых слота + RGB-палитра со слайдерами и полем HEX
- **Толщина и тип линии**: сплошная, пунктир, волнистая
- **Масштаб 10%–900%** (рядом с «+» внизу справа); толщина линий на холсте не меняется при приближении/отдалении
- **Фон**: белое/чёрное полотно переключается одной кнопкой; сетка всегда на белом фоне
- **Шаблоны**: координатная плоскость (без числовых значений), числовая ось
- **После вставки фигуры или шаблона** инструмент автоматически возвращается к кисти
- **Страницы**: несколько холстов с переключателем внизу справа (+, ‹ ›)
- **Отмена/возврат** (Ctrl+Z / Ctrl+Y), горячие клавиши
- **Экспорт в PNG**
- **Автосохранение** в браузере (localStorage) — рисунки не пропадают после перезагрузки

## Запуск локально

```bash
bun install   # или npm install
npm run dev   # http://localhost:3000
```

## Публикация (GitHub Pages)

Сайт публикуется автоматически: репозиторий содержит воркфлоу
`.github/workflows/deploy.yml`, который при каждом push в `main`
собирает статический экспорт (`npm run build:static`) и деплоит его
на GitHub Pages. Включать Pages вручную не нужно — это происходит
при первом запуске воркфлоу.

Ссылка на сайт: `https://<ваш-ник>.github.io/whiteboard/`

> Если назовёте репозиторий иначе — поменяйте `/whiteboard` в
> `NEXT_PUBLIC_BASE_PATH` внутри `.github/workflows/deploy.yml`
> на имя вашего репозитория.
